# 🎬 סרטוני מערכת — "ככה זה נראה מבפנים"

זרוק לתיקייה הזו הקלטות מסך אמיתיות מהמערכת — והדף יזהה אותן **אוטומטית** ויחליף את התמונות בנגן. בלי לגעת בקוד, רק לרענן את הדף.

## שמות הקבצים (חובה בדיוק כך)

| קובץ | פרק בנגן | מה כדאי להקליט |
|---|---|---|
| `create.mp4` | יצירת קורס | בורדי בונה קורס → עמוד עריכת הקורס → העלאת שיעור |
| `club.mp4` | הפעלת מועדון | הפעלת המועדון → פיד חי → אירועים / לייב |
| `data.mp4` | ניתוח נתונים | לוח בקרה → מסך נתונים → כרטיס תלמיד ב-CRM |
| `mail.mp4` | דיוור אוטומטי | יצירת סדרה → עורך הבלוקים → מסך הסדרות |

אפשר להעלות רק חלק — פרק בלי סרטון ימשיך להציג את צילומי המסך.

## מפרט מומלץ

- **פורמט:** MP4 (H.264) — הכי בטוח לדפדפנים
- **יחס:** 16:9, רזולוציה 1920×1080 (או 2560×1440)
- **אורך:** 10–25 שניות לפרק, עדיף לולאה שנסגרת יפה
- **אודיו:** לא צריך — הנגן מנגן מושתק
- **משקל:** עד ~25MB לקובץ (אם ההקלטה כבדה, לכווץ ב-HandBrake / Compressor)
- **תוכן:** מצב בהיר (light), עברית, בלי מידע אישי אמיתי על המסך

## בונוס — סרטון הרקע של ה-Hero

קובץ בשם `hero-bg.mp4` שמונח **בתיקייה `assets/` הראשית** (לא כאן) יופעל אוטומטית כרקע נגלל ב-Hero של הדף.
