Connect Make — automations

Connect Make.com with an API key and a webhook — every lead, purchase, and cancellation flows to your automations in real time

Available on the Educator plan and up

WHITEBOARD has an official app on Make — with ready-made modules (like add student, which adds a student to a course) and a clear guide for connecting your courses. Through it, you connect the platform to any external process: a purchase at your payment provider that automatically becomes a student in a course, a new lead sent to WhatsApp, a subscription cancellation that triggers an alert. The connection works in both directions — an API key that identifies your account, and a webhook that receives every event in real time.

Here's a real scenario built on the app — capturing purchases from the payment provider and routing them as students into the right courses:

The full setup guide is available inside the platform: Settings → Integrations → Make.com → "?" → Setup guide.

1Create an API key in WHITEBOARD

In Settings → Integrations, on the Make.com card, click Create API key. A key unique to your account is created and shown on screen.

2Copy the key

Click the copy button next to the key (it starts with wb_). The full key is shown only once — save it before you move on.

Heads-up

Lost the key? Create a new one — but that revokes the old one immediately, and any scenario using it will stop working until you update it.

3Add a connection in Make.com

In Make.com → New Scenario → add a WHITEBOARD module → Add connection → paste your API key into the API Key field and click Save.

4Copy the webhook URL

Copy the scenario's webhook URL from Make (it starts with hook.eu2.make.com) and paste it into the Webhook URL field on the Make.com card in WHITEBOARD — this is where every new event will be sent: lead, purchase, cancellation.

5Map fields and turn it on

In Make, map the fields coming from WHITEBOARD (name, email, product, amount) to the actions you want — a WhatsApp message, a row in Google Sheets, whatever you build — and click ON. Test with Run once and a demo event.

What you get

  • Payments connection — the app is how you connect your payment provider to your courses: a purchase webhook comes in, an add student module adds the customer to the course. The full guide: Payments and getting paid.
  • Real-time events: new leads, purchases, and subscription cancellations.
  • One API key for all the courses and clubs in your account.
  • Cancellation alerts — the integrations screen has a Subscription cancellation reminders toggle that sends an alert through the webhook when a subscription is canceled or about to end, to the recipients you set.
  • Send test — sends a demo message to the webhook to confirm the pipeline works.

What's next

The events sent to Make are born in the CRM — worth getting to know CRM — all your contacts in one place. And if you're waiting on Zapier — it's marked "coming soon" in the integrations overview.
