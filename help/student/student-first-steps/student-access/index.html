גישה מהירה — שהקורס תמיד יהיה זמין

שמירת קיצור לקורס בטלפון ובמחשב, הישארות מחוברים, ומה עושים כשאין אינטרנט יציב

הקורס שלכם זמין מכל דפדפן, בכל מכשיר. כמה צעדים קטנים יחסכו לכם את החיפוש אחרי הקישור בכל פעם מחדש.

1שומרים את הקישור הנכון

הכתובת שאליה נכנסים היא הקישור שקיבלתם מהמרצה (או כתובת בית הספר / המועדון שלו). שמרו אותה כסימנייה בדפדפן — ותגיעו לשיעור בלחיצה אחת.

2מוסיפים קיצור למסך הבית בטלפון

  • אייפון (Safari): פותחים את הקורס ← כפתור השיתוף ← הוסף למסך הבית.
  • אנדרואיד (Chrome): פותחים את הקורס ← תפריט שלוש הנקודות ← הוספה למסך הבית.

מעכשיו הקורס נפתח מהטלפון כמו אפליקציה.

3נשארים מחוברים

מתחברים פעם אחת מהמכשיר האישי — והמערכת זוכרת אתכם בכניסות הבאות. אם אתם על מחשב ציבורי או משותף, עדיף להתנתק בסיום.

טיפים לצפייה חלקה

  • ההתקדמות שלכם נשמרת אוטומטית — אפשר לעצור באמצע שיעור ולהמשיך מאותה נקודה ממכשיר אחר.
  • אינטרנט איטי? נסו להוריד את איכות הווידאו בנגן.

מה הלאה

מחוברים ומסודרים? עכשיו שווה להכיר את כלי הלמידה — הפתקים שלי והשיחה עם בורדי.
