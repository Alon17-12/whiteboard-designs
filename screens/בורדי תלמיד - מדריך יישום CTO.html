בורדי תלמיד

עוזר ה-AI היחיד שמשרת את התלמיד: צ'אט פנימי בתוך נגן הקורס, מיומן על תמלולי הווידאו של השיעורים, מודע למיקום התלמיד על ציר הזמן, ועונה אך ורק לפי חומר הקורס. מדריך זה נלווה לאפיון (§18) — שם מה ולמה, כאן איך בונים.

1 סקירה והחלטות מפתח

בורדי תלמיד רץ על אותו Runtime משותף של שאר הבורדים (Claude מאחורי LLMProvider + tool-calling + RAG). מה שחדש כאן הוא קהל היעד (תלמיד), הסקופ (קורס בודד), ומקור הידע (תמלולי וידאו) — שדורש צנרת תמלול חדשה.

החלטההכרעה
קהלהתלמיד הרשום לקורס (לא המרצה)
סקופ ידעקורס אחד בלבד — namespace וקטורי פר-קורס, סינון קשיח
מקור ליבהתמלולי הווידאו של כל השיעורים (+ קבצים/קישורים/חומרי מרצה)
מודעותיודע את מיקום התלמיד (lesson_id + t) ומשקלל אותו באחזור
חוזה תשובהcourse-only — עונה רק מקטעים שאוחזרו; מחוץ לסילבוס → מסרב בנימוס
מנגנון UIפאנל צ'אט בנגן, זהה למנגנון "הפתקים שלי" (togglePanel)
גייטינגמסלול מנהיג · בורדי אחד למרצה · קורס אחד · הקמה ידנית
עיקרון-על: כמעט הכל נשען מחדש על הקיים (Runtime, pgvector RAG, Trigger.dev, מנגנון הפאנל בנגן). החלק היחיד שבאמת חדש הוא צנרת התמלול והאינדוקס שלה — עליה נתמקד.

2 חוויית התלמיד

התלמיד צופה בשיעור. מהסטריפ הימני הוא פותח את פאנל בורדי (בדיוק כמו "הפתקים שלי"). הפאנל:

  • Badge מודעות-מיקום — "יודע איפה אתה: שיעור 12 · 14:32". זה מה שמאפשר תשובות בהקשר ("זה בדיוק מה שמוסבר עכשיו").
  • ציטוט מקורות — כל תשובה נושאת שבבי מקור: שיעור 11 · 08:20 לחיצים → קפיצה לנגן.
  • סירוב מחוץ-לסילבוס — שאלה שלא נלמדה → "אני עונה רק לפי החומר של הקורס הזה" + הפניה למה שכן נלמד.
  • שאלות מוצעות — "סכם לי עד כאן", "תן דוגמה", "מה כדאי לחזור עליו".
המסך: מסכים מחודשים/בורדי/בורדי תלמיד - שיחה בקורס.html. הפאנל נבנה כרכיב בתוך נגן הקורס הקיים (צפייה בקורס.html), על אותו דפוס .sb-panel / togglePanel('boardi') שכבר קיים שם כ-stub.

מיקום ב-UI + מסכי האפסייל (שערי-מסלול)

הקמת/ניהול בורדי תלמיד יושבים כטאב "בורדי" בתוך הגדרות הקורס (לצד ליי-אאוט/הגדרות/התלמידים/אנליטיקס), עם תג קטן מנהיג. הטאב תמיד גלוי — מה שמשתנה הוא מה שקורה בלחיצה, לפי המסלול והמצב:

מצב המרצהמה קורה בלחיצה על הטאבמסך
מסלול מנהיג · אין בורדימסך הקמה רגילבורדי תלמיד - הקמה וניהול.html (מצב הקמה)
מסלול מנהיג · יש בורדימסך עריכה/ניהול. ניסיון ליצור בורדי נוסף → אפסייל ארגוניבורדי תלמיד - אפסייל ארגוני.html
לא מסלול מנהיג (מורה/מחנך)תצוגה נעולה + אפסייל מנהיגבורדי תלמיד - אפסייל מנהיג.html
האפסיילים הם UI בלבד — האכיפה בשרת. ה-gate האמיתי הוא ב-wbApi.createStudentBoardi: בודק plan==='leader' ואת אילוץ הייחודיות, ומחזיר שגיאת-מסלול מובנית (PLAN_REQUIRED / LIMIT_REACHED) שה-UI ממפה לפופאפ הנכון. אסור להסתמך על הסתרת הטאב.

אפסייל ארגוני → ליד מכירות

בפופאפ הארגוני, "דבר עם נציג מכירות" פותח טופס לידים (שם, טלפון, אימייל, מספר קורסים מבוקש, הערה). שליחה יוצרת ליד ב-CRM/אדמין דרך POST /api/leads עם:

lead { name, phone, email, requested_courses, note,
       source: 'boardi_upsell', requested_plan: 'enterprise',
       teacher_id, current_plan: 'leader', created_at }
// מופיע במסך האדמין (CRM) עם תיוג "ליד ארגוני · מקור: אפסייל בורדי" + נותב לנציג מכירות
הטופס הוא הצד הלקוח; היעד הוא רשומת-ליד אמיתית ב-CRM/אדמין (לא רק טוסט). לאחר יצירה — אישור לתלמיד/מרצה "נציג יחזור תוך יום עסקים" + אירוע אנליטיקס enterprise_lead_created.

4 צנרת התמלול חדש

החלק היחיד שבאמת צריך לבנות. הופך וידאו → ידע בר-אחזור:

וידאוBunny Stream
←
transcribe-lessonsWhisper / Groq
←
תמלול + חותמותwords[] · segments
←
chunkingחלונות 30–60ש׳
←
embeddingspgvector · namespace/קורס
// jobs/transcribe-lessons.ts — פר-שיעור, רקע (Trigger.dev)
export const transcribeLessons = job("transcribe-lessons", async({courseId})=>{
  for (const lesson of getLessons(courseId)) {
    const audio = await bunny.pullAudio(lesson.videoId);       // אודיו מה-Stream
    const tr    = await stt.transcribe(audio, { timestamps: "word" });
    await db.lesson_transcript.upsert({ lessonId: lesson.id, courseId,
      text: tr.text, words: tr.words, status: "done" });
    await enqueue("index-transcripts", { lessonId: lesson.id });   // → אינדוקס
  }
});
// jobs/index-transcripts.ts — chunk + embed לתוך namespace הקורס
const chunks = windowize(transcript.words, { seconds: 45, overlap: 8 });  // שומר t_start/t_end
for (const c of chunks) {
  const emb = await embed(c.text);
  await db.transcript_chunk.insert({ lessonId, courseId, t_start:c.a, t_end:c.b, text:c.text, embedding:emb });
}
המרצה רואה את הצנרת כסטטוס תמלול פר-שיעור במסך ההקמה (מתומלל ✓ / בתהליך % / ממתין) + כפתור "תמלל את כל השיעורים". השאר קורה ברקע.

5 אחזור מודע-זמן + חוזה תשובה

אחזור (course-scoped + position-boost)

// retrieve.ts — סינון קשיח לקורס + boost למיקום התלמיד
const hits = await db.sql`
  SELECT id, lesson_id, t_start, t_end, text,
         embedding <=> ${qEmb} AS dist,
         CASE WHEN lesson_id = ${cur.lessonId} THEN 0.15 ELSE 0 END AS pos_boost
  FROM transcript_chunk
  WHERE course_id = ${courseId}                    -- ← אף פעם לא חוצה קורס
  ORDER BY dist - pos_boost ASC LIMIT 8`;

חוזה תשובה — course-only

שער האמון של הפיצ'ר. ה-system prompt מחייב: "ענה אך ורק מהקטעים שסופקו. אם אין כיסוי — אמור שזה לא נלמד בקורס והצע מה כן. אל תשתמש בידע חיצוני." זה מה שמונע הזיות — והוא ההבדל בין "עוזר שסומכים עליו" ל"צ'אטבוט שממציא".
// system prompt (מקוצר)
אתה עוזר הקורס של WHITEBOARD. ענה בעברית, בהקשר למיקום התלמיד (${lessonTitle} · ${mmss}).
השתמש אך ורק במקורות המצורפים. אין כיסוי → "זה לא נלמד בקורס הזה" + הפניה למה שכן.
ציין מקור לכל טענה: (שיעור N · mm:ss).  רמת היצמדות: ${strictness}.

ברירת המחדל strictness = "course_only". המרצה יכול לרכך ל-"course_plus_general" (ידע כללי בזהירות, עדיין מסמן מה מהקורס ומה לא).

7 מודל נתונים

table student_boardi { id, teacher_id, course_id, status, persona, strictness, greeting, created_at }
table lesson_transcript { lesson_id, course_id, text, words:jsonb, status }        // status: pending|running|done
table transcript_chunk { id, lesson_id, course_id, t_start, t_end, text, embedding:vector }  // pgvector
table student_boardi_material { id, boardi_id, kind, ref, title }               // kind: file|test|link
table student_boardi_thread { id, student_id, boardi_id, course_id, messages:jsonb, updated_at }
הכל מסונן RLS: student_boardi פר-teacher_id; student_boardi_thread פר-student_id; אחזור פר-course_id. תלמיד ניגש רק לקורס שהוא רשום אליו.

10 גבולות, פרטיות ועלות

  • אנטי-הזיה — course-only contract + ציטוט חובה; "לא יודע" עדיף על ניחוש.
  • Tenancy — אחזור נעול ל-course_id; threads פר-תלמיד; בדיקת enrollment בכל שאלה.
  • פרטיות תלמיד — שיחות התלמיד פרטיות; המרצה לא רואה שיחות פרטניות (אלא אגרגט/הסכמה — החלטת מוצר).
  • עלות — תמלול (חד-פעמי/שיעור) + אינדוקס + inference; תקרות פר-בורדי/חודש במסלול מנהיג.

13 השלכות פיתוח + מפת דרכים

מה חדש (לבנות)

  • צנרת תמלול (STT) + אחסון תמלולים עם חותמות זמן.
  • אינדוקס וקטורי לתמלולים ב-namespace פר-קורס.
  • אחזור course-scoped + position-boost.
  • פאנל צ'אט התלמיד בנגן + מסך הקמה/ניהול (מרצה).
  • גייטינג מנהיג + מגבלת 1/קורס + ניהול מחזור-חיים + תקרות עלות.
